Código Clave del Ejercicio

1. Solicitud de Permisos (Cliente): 
const permission = await Notification.requestPermission();
if (permission === 'granted') {
  console.log('Permiso concedido para notificar');
}
2. Disparo en el Service Worker (sw.js): 
self.registration.showNotification(title, {
  body: 'Mensaje de la notificación',
  icon: 'icons/icon-192.png',
  vibrate: [200, 100, 200],
  tag: 'mi-alerta-local'
});
