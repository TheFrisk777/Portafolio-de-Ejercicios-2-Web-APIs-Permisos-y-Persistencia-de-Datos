Arquitectura y Funcionamiento Técnico

Cómo interactúan la API de Medios y el Canvas HTML5

1

Petición de Acceso con getUserMedia

Se invoca navigator.mediaDevices.getUserMedia(constraints) enviando parámetros de video (resolución, id de dispositivo o facingMode). El navegador solicita el consentimiento al usuario.

2

Flujo de Video en <video>

La promesa devuelve un MediaStream que se asigna directamente a video.srcObject = stream. El elemento reproduce los cuadros a 30-60 FPS con aceleración de hardware.

3

Captura Estática a <canvas>

Al accionar el obturador, se ajusta el ancho y alto del canvas al video.videoWidth y video.videoHeight reales, y se dibuja el fotograma exacto con ctx.drawImage(video, 0, 0).

4

Exportación y Procesamiento

La imagen en el canvas se puede procesar píxel a píxel, aplicar filtros con ctx.filter, o exportarse a formato PNG/JPEG mediante canvas.toDataURL() o canvas.toBlob().
